# Scenivox documentation artwork

Original, editable SVG illustrations authored for the repository homepage:

- `scenivox-mark.svg`: compact frame-aperture wordmark symbol.
- `scenivox-architecture.svg`: scene/revision and persistence-boundary illustration; planned integrations are visibly separated.
- `scenivox-og.svg`: landscape repository cover for sharing and previews.

Each asset uses inline vector geometry and system font fallbacks. No externally sourced photographs, stock assets, custom fonts, generated product screenshots, or unsupported implementation claims are embedded. Artwork communicates project direction and is not evidence of a working renderer. The repository's software license remains undecided; these assets carry no separate licensing grant.
